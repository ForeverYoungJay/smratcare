# Phase 3B-3 财务部工作台

## 已完成

- 财务员工工作台：收银台、收费登记、收款流水、发票收据、退款冲正、日结交班和标准工作顺序。
- 财务部长工作台：今日经营风险、欠费规模、低余额账户、待审核费用、账务异常和月结进度。
- 员工和部长复用现有财务汇总接口，但使用不同岗位语义和操作入口。
- 员工版明确将金额标记为“机构当日收银口径（非个人业绩）”，不把机构总额冒充员工个人绩效。
- 普通员工不展示审批、欠费管理和月结管理快捷入口；部长版增加对应管理入口。
- 闭环状态同时使用文字和符号，操作按钮保留键盘焦点样式，并适配常见办公屏幕。

## 数据源

- `/api/finance/workbench/overview`：机构今日收款、退款、支付方式、欠费、审批、对账异常和月结风险。
- 现有路由复用：收银台、收费登记、收款流水、发票收据、退款冲正、欠费跟进、对账异常、退住结算、日结交班、月结和审批。
- 本阶段未增加或伪造后端业务接口。

## 数据范围与后端缺口

- 财务工作台汇总接口当前只有机构口径，没有收银员或当前操作人参数。
- 收款分页虽返回 `operatorStaffId`，但不支持服务端按当前操作人过滤；前端没有通过扩大分页后再本地过滤的方式伪造个人统计。
- 后端后续应提供按登录员工安全限定的“本人今日收款、退款处理、票据补齐和最近操作记录”接口。接入前，员工工作台只展示机构当班参考数据并明确数据口径。
- 部长版的人员任务分配和员工完成情况仍缺少聚合接口，本阶段不从机构总额推算个人绩效。
