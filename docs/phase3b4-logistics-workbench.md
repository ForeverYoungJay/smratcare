# Phase 3B-4：后勤部工作台

## 已完成

- 员工版优先展示报修、出入库、房态、清洁和送餐操作。
- 部长版优先展示逾期维修、库存预警、采购审批和设备临期。
- 复用现有 `/api/logistics/workbench/summary`，不增加或伪造接口。
- 现有接口不支持按责任人过滤，因此员工指标明确标注为“机构当班任务口径（非个人绩效）”。
- 人员任务分配与完成情况保留明确空状态，等待后端提供可靠聚合接口。

## 验收重点

- 员工不显示采购审批、设备管理等部长操作。
- 部长可从工作台两次点击内到达风险和审批页面。
- 指标、操作和工作顺序均经过统一路由权限过滤。
